# Codex model breakpoint — preregistration

Hypothesis: GPT-6-Luna at low effort passes at least 20 percentage points fewer hard tasks than GPT-6-Astra at high effort.

Before model calls: four arms (gpt-6-luna / gpt-6-astra × low / high), 10 hard and 5 easy tasks, two fresh-repository repetitions per task. The [Grok study](../grok-model-breakpoint/)'s hard tasks were not available to reuse, so build original synthetic Python multi-file tasks with external hidden pytest tests. Randomize order with seed 17. No GPU required.

Decision rule: primary endpoint is all hidden tests passing on hard tasks. Compute one-sided Fisher exact test (strong-high greater than cheap-low). PROVEN requires observed gap >=20 points, Fisher p<0.025 (two-round alpha allocation), and task-cluster bootstrap 97.5% lower bound >=20 points. DISPROVEN requires task-cluster bootstrap 97.5% upper bound <20 points; otherwise inconclusive. Repetitions are clustered by task for CIs; Fisher is reported but assumes independent trials and is supplementary to the cluster requirement. Easy tasks and middle arms are descriptive. If round 1 is inconclusive, round 2 adds 20 NEW hard tasks and repeats all arms twice; analyze round 2 independently. Stop after two rounds. Infrastructure failures are missing, never wrong answers; if unavailable arms prevent inference, verdict remains STILL INCONCLUSIVE.

Identical 240-second timeout per call; no context/token cap, no delegation. Hidden tests are withheld from the work directory, evaluated only after the call. Save JSON events and usage, patches and test reports. Validate reference solutions before runs. Standard API-equivalent prices per million input/cached/output tokens: Luna $0.10/$0.01/$0.50; Astra $10/$1/$50, https://developers.openai.com/api/docs/pricing (2026-10-15). Uncached=input-cached; cache writes unavailable in CLI are excluded and disclosed. Not a bill.

CLI help and local models_cache.json inspected: both models support low/high; config contains trust entries and no model override. Luna is the cheapest named general model in the local catalog; Astra is the strongest tier. GPU: none. Experiment CU: 0. Compute used: 0 CU.

Pre-run boundary safeguard: a percentile bootstrap degenerates at a ceiling. Decision bounds therefore also include a conservative task-level Clopper–Pearson bound: lower gap = lower(strong all-reps-pass) − upper(cheap any-rep-pass); upper gap = upper(strong any-rep-pass) − lower(cheap all-reps-pass), each binomial tail alpha=.0125. Use the wider of this and the bootstrap interval. This remains conservative with correlated repeats and prevents a tiny perfect suite falsely settling the hypothesis. CLI usage exposes cache_write_input_tokens; charge it separately when present.

Execution notes: four concurrent experimental CLI calls, seeded shuffled order, same system/config treatment for all arms. The Codex account was shared with other work running at the same time; cache/latency comparisons are descriptive. Initial evaluator dependency was missing; installed pytest and regraded the unchanged first saved solution. Reference validation completed after calls were launched (a procedural deviation from the planned before-run validation); all 15 references pass. No outcomes were used to alter tests or references.

Audit details: shuffle seeds are 17+round (18 and 19), rather than literal 17 stated above. This is an implementation deviation with no outcome-based ordering. Model availability probes both returned OK. The round-2 preparation includes 40 seeded generated boundary cases per task plus hand-picked cases, with validation before activation. Twenty-two independently hand-computed oracle checks pass (results/oracle-hand-checks.json). All raw task results, including an easy cheap-low no-edit failure, remain in the dataset.

Model scope: Luna is the cheapest *listed, publicly priced general model* in the local catalog. Hidden entries gpt-reserve and codex-auto-review are excluded; no official standalone price for gpt-reserve was found. The older listed GPT-5.6-Luna costs $0.20 input / $1.20 output per million (https://developers.openai.com/api/docs/models/gpt-5.6-luna), above GPT-6-Luna. Astra is described by the catalog as frontier intelligence for the most demanding work.
