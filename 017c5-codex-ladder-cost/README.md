# 017c5: preregistered Codex token-cost ladder

Hypothesis: Astra/high uses meaningfully more total tokens than Luna/low at the pass-rate ceiling. This is an empirical comparison of the two specified configurations, not a pricing comparison.

## Fixed design and decision rule (before fresh calls)
Reuse the round-4 frozen 24 synthetic tasks: 12 tier 3 and 12 tier 4, unchanged fixtures and hidden grader, originally derived from round 3. One fresh run per task per arm (48 completed calls), concurrency 4, 600 seconds per attempt. Fixed shuffled schedule seed 1705; no historical outcomes pooled. Original, round-3 and round-4 directories are read-only. Default Codex account; CODEX_HOME is unset in this environment and will not be overridden. No Claude or Grok needed.

Primary estimand is exp(mean(log(Astra total tokens / Luna total tokens))) across 24 pairs. Total tokens = input_tokens + output_tokens + reasoning_output_tokens, counting reasoning separately exactly as requested; raw fields retained so any overlap in provider accounting is visible. Also report input+output sensitivity and the paired geometric-mean wall-clock ratio (secondary). Cached input remains included. Wall time covers CLI execution and snapshotting, before grading, as inherited. Paired percentile bootstrap 95% CI, 20,000 resamples, NumPy default_rng seed 1705, resample whole task pairs. PROVEN if the primary CI lower bound >1.25. DISPROVEN if its upper bound <1.25, meaning no meaningful token penalty. The 25% threshold is user-fixed and represents at least one extra token per four baseline tokens. Equality/straddling after the fixed 24-pair sampling budget gives STILL INCONCLUSIVE; no post-hoc widening, extra calls, or forced verdict. Wall ratio does not override the primary verdict. Pass rates are descriptive, two-sided 95% Clopper-Pearson exact CIs, with failing tasks listed.

Power planning: with paired log-ratio SD 0.30, n=24 yields SE .06124 and approximate 95% halfwidth .1200 (multiplicative 1.1275). Normal approximation P(CI entirely above log(1.25)) is Phi((log(R)-log(1.25))*sqrt(24)/.30 -1.96): at R=1.6, about 98.1%. For no penalty R=1.0, reverse probability is Phi(log(1.25)*sqrt(24)/.30-1.96), about 95.4%. Thus both outcomes are feasible under explicit assumptions; near-threshold effects or greater variance remain hard. At SD .50 these powers fall to roughly 67.7% and 58.9%. The fixed n is obeyed, not adapted to outcomes.
