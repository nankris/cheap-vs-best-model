# Trimmed Codex difficulty ladder: preregistration, fixed before fresh calls

Hypothesis: gpt-6-astra/high has higher tier-4 all-tests pass probability than gpt-6-luna/low. Same pinned configurations and synthetic tasks/harness as the previous (unpublished) round of this ladder. The [original Codex model-breakpoint study](../codex-model-breakpoint/) and that round's directories are read-only sources; no old outcomes enter this analysis.

Design: 12 tier-3 tasks and 12 tier-4 tasks, one fresh repetition per arm, 48 calls, four concurrent CLI tasks, fixed shuffle seed 1703. Tier 4 uses the first 12 tasks in original suite order, without outcome selection. That earlier round contained only five tier-3 tasks: retain all five and apply its identical batch template to its first seven tier-4 algorithms, new IDs T45–T51; no new algorithms or grader design. Thus tiers partly overlap in algorithm, but primary analysis uses only tier 4. Earlier rounds exhausted runtime with an oversized 176-call schedule; this design reduces repetitions, tiers and task count, and caps concurrency at four. Validation precedes calls. Deadline three hours from runner start. At most 600 seconds per attempt; infrastructure errors are retained and retried, never scored as failures. Resume skips atomic completed result.json files. Raw events stream directly to local disk, source snapshots and grading are saved on every completion.

DECISION RULE (unchanged from the previous round): task differences Astra pass minus Luna pass. Paired task bootstrap, 100,000 resamples, seed 1703, percentile 95% CI. PROVEN if lower bound >0 and one-sided exact task sign p<.05. DISPROVEN if upper bound <0 and reverse sign p<.05, or entire CI strictly inside [-.10,.10]. Superiority takes priority. Margin is one extra failed repair per ten tasks, the largest negligible routing deficit. All-zero differences replace degenerate bootstrap with ±(1-.05**(1/n)); other constant differences use the original Hoeffding guard. No early claims or extra sampling. Tier 3 descriptive only.

Power/feasibility: n=12 tier-4 tasks. Under gap .40 and task-difference SD .45 normal planning power Phi(.40*sqrt(12)/.45-1.96) is about .869; at gap .25 SD .35 it is .696. These are assumptions, not guarantees. Exact sign requires at least five favorable discordances with none unfavorable (p=.03125). Crucially, the retained all-zero guard gives ±22.09 points at n=12; even perfect agreement cannot establish 10-point equivalence. n>=29 would be required. With one binary repetition per arm, any nonzero difference contributes at least 8.33 points, so this design is poorly sized for equivalence. I kept n=12 and the original rule rather than resizing the design to make both outcomes reachable; I do not weaken the guard or claim ceiling equivalence. If no decision criterion holds after the fixed sample, report STILL INCONCLUSIVE at the fixed sampling-budget limit and state whether wall time actually ran out.

Inference is limited to purposive synthetic algorithms sharing journal machinery. It compares model plus effort, not effort alone. Hidden tests/reference remain outside CLI mount namespace; use the inherited isolation harness and a saved probe. Default Codex account only. No network or subagents are permitted inside trials.

GPU: none; CU used: 0. CPU grading and account-backed CLI only. Public/synthetic data only. Reproduce: `python scripts/validate.py; python scripts/run.py; python scripts/analyze.py`. Suite is copied/frozen in private/suite.json; do not rerun inherited build.py (it generates the untrimmed suite).
